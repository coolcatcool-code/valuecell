## 💻 代码示例

所有文档中的代码示例都可以在以下位置找到：

- **示例代码**: `examples/` 目录
- **测试代码**: `python/valuecell/*/tests/`
- **智能体实现**: `python/valuecell/agents/`

### 运行示例

```bash
# 1. 克隆仓库
git clone https://github.com/ValueCell-ai/valuecell.git
cd valuecell

# 2. 安装依赖
bash start.sh

# 3. 运行示例
cd python
uv run python examples/backtest_simple_ma_cross.py
```

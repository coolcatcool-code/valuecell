## ValueCell 是什么

一句话：**和一个从不睡觉的 AI 投资顾问对话，让它帮你研究、追踪、甚至交易。**

打开 ValueCell，你面对的不是一堆按钮和表单，而是一个输入框。你想做的所有
事情——查一家公司的财报、追踪一只股票、设置自动交易策略、订阅新闻——
都是**打字告诉它**，不是在菜单里找功能。这份指南会带你走一遍每一类事情
具体怎么说、说完会发生什么。

## 开始之前

- 确认服务已经跑起来：浏览器打开 `http://localhost:1420`（如果你按
  [部署指南](./DEPLOYMENT_GUIDE_CN.md)用 Docker 部署，这是默认地址）
- 确认 `.env` 里至少配置了一个 LLM Provider Key——没配的话后端会在启动时
  直接报错退出（这是设计好的保护机制，不是随机故障，参见
  [RELEASE_CN.md](./RELEASE_CN.md)）
- 第一次打开，你会看到一个几乎空白的欢迎界面，中间是一个呼吸的品牌
  标记和一句问候，下面是三张建议卡片（Deep Research / Auto Trading /
  Pushing News）——这就是全部的初始状态，没有仪表盘、没有向导，直接开始
  打字就行

## 界面导览

### 顶部栏

屏幕最上方一条很窄的横条，从左到右：

- **左侧**：ValueCell 品牌标记 + 名字，点击回到首页
- **右侧四个图标**：
  - **市场图标**（柱状图形状）→ 打开 [智能体市场](#核心用法六智能体市场)
  - **对话气泡图标** → 打开历史对话列表（侧边抽屉，可以找回之前的任何一次会话，也能删除）
  - **齿轮图标** → 打开[设置](#设置)
  - **⌘ K**（Mac 上按 `Cmd+K`，Windows/Linux 按 `Ctrl+K`）→ 打开命令面板

顶部栏就是你在这个产品里**唯一**需要记住的固定导航——没有侧边栏，没有
第二层菜单。

### 命令面板（⌘K）

任何页面按下 `Cmd/Ctrl + K`，会弹出一个居中的搜索框，分三组：

- **Recent**：最近的历史对话，点击直接跳回那次对话
- **Summon an advisor**：当前已启用的智能体列表，点击直接开始和它对话
- **Jump to**：跳转到"对话首页 / 智能体市场 / 设置 / 记忆管理"

输入文字会实时过滤这三组结果——比如输入 `market` 只会剩下 "Agent Market"
这一项。这是除了首页输入框之外，你会最常用的第二个入口。

### 首页（Home）

左侧是主对话区，右侧是"我的自选"（Watchlist）栏。第一次使用时，主区域
只有欢迎语和输入框；一旦你和智能体产生过对话，主区域会变成任务卡片流，
显示最近的智能体活动摘要，底部固定一条输入框可以随时继续问下去。

### 股票详情页

点击自选列表里的任意一只股票，会打开它的详情页：当前价格、60 天走势图、
所属行业、公司简介。页面顶部有一个"Remove"按钮可以把它从自选里移除。

## 核心用法一：直接对话

首页的输入框默认接到 **ValueCell Agent**（超级智能体）——这是整个系统的
调度中枢，你不需要先想清楚"这个问题该找哪个智能体"，直接把问题打出来，
它会自己判断：

- 简单问题（比如"苹果现在多少钱一股"）它会直接回答
- 复杂任务（比如"帮我研究一下特斯拉值不值得买，如果值得就设置自动交易"）
  它会拆解成多个步骤，调用对应的专业智能体，把结果汇总给你

**示例问法**（这些不是我编的，是系统自带的例句）：

- "Setup trading with $100,000 for BTC-USD and ETH-USD using DeepSeek, Grok, Claude model"
- "What was Apple's revenue in Q4 2024? Provide the filing source."
- "What's the latest news about artificial intelligence?"

回复是流式的——文字会一个词一个词地出现，AI 消息前面有一个小圆点在轻轻
"呼吸"，表示它正在工作；如果它调用了工具（比如查了一份财报），你会看到
一段可展开的"正在做什么"过程说明，而不是黑箱直接吐结果。

**继续追问**：在同一个对话里接着问，上下文会保留。想开一个新话题，直接
去首页重新打字即可（不需要手动"新建对话"）。

## 核心用法二：管理自选股

右侧"My Watchlist"栏：

- **添加**：点击栏目底部的 **Add Stocks** 按钮，弹出搜索框，输入公司名称
  或代码，找到后点右边的 **Watchlist** 按钮加入（已加入的会显示
  **Watched**，按钮变灰不可重复点）
- **查看**：点击列表里任意一只股票，跳到详情页
- **移除**：在详情页点击 **Remove**

也可以完全靠说的——直接在对话框里说"帮我关注一下英伟达"，效果是一样的，
这也是这个产品的设计原则：**任何操作都应该既能点，也能说**。

## 核心用法三：深度研究（Research Agent）

这是负责"读财报、查公司信息"的智能体。它能做（也是系统内置的示例问法）：

- **提取财务数据并标注来源**："What was Apple's revenue in Q4 2024? Provide the filing source."
- **分析机构持仓（13F 文件）**："What are the top holdings of Berkshire Hathaway in the latest 13F filing?"
- **综合分析并引用来源**："Summarize analyst commentary on Apple's guidance and cite sources."
- **监控新公告**：跟踪某公司的最新 SEC 文件（10-K 年报 / 10-Q 季报 / 8-K
  重大事件 / 13F 机构持仓）

它的答案会**标注数据来源**（哪份文件、哪个部分），不是凭空生成的总结——
这是它和普通聊天机器人最大的区别。第一次和它对话，界面上会显示
"Welcome to Research Agent!"，直接在下面的输入框打字即可开始。

## 核心用法四：自动交易（Auto Trading Agent）

负责加密货币的技术分析和自动化交易。**配置方式是纯对话式的**，没有一个
表单让你逐项填写——直接告诉它你想怎么做：

```
Setup trading with $100,000 for BTC-USD and ETH-USD using DeepSeek, Grok, Claude model
```

```
Configure auto trader with $50,000 capital, trade BTC-USD, ETH-USD, SOL-USD with 1.5% risk
```

```
Setup trading agent with default settings for Bitcoin
```

**默认风控参数**（不特别指定的话就是这些）：

| 参数 | 默认值 |
|---|---|
| 单笔交易风险 | 总资金的 2% |
| 最大同时持仓数 | 3 个 |
| 检查间隔 | 60 秒 |

**用到的技术指标**：MACD (12/26/9)、RSI (14)、EMA (12/26/50)、布林带
(20, 2σ)——AI 会综合这些信号给出买卖判断，并附上置信度和理由。

**关于风险，必须说清楚的事**：

- 默认是**纸上交易**（模拟盘），不会碰你的真实资金
- 要接入真实交易所（目前支持 OKX），需要在部署时的 `.env` 里配置
  `AUTO_TRADING_EXCHANGE=okx` 和对应的 API 密钥
- 就算配置了交易所密钥，`OKX_ALLOW_LIVE_TRADING` 默认还是 `false`，
  必须手动改成 `true` 才会执行真实交易——这是两道独立的开关，缺一不可，
  是刻意设计的双重确认
- **强烈建议**：先跑纸上交易至少一到两周，观察它的决策是否符合你的
  预期，再考虑开实盘，而且从小资金开始

启动后可以直接问它"现在的持仓怎么样""这笔交易为什么买"，它会用同样的
对话方式回答，不需要去找单独的报表页面。

## 核心用法五：新闻推送（News Agent）

负责实时新闻搜索和监控，示例问法：

- **搜索新闻**："What's the latest news about artificial intelligence?"
- **突发新闻**："Any breaking news right now?"
- **财经新闻**："What's happening in the stock market today?"

也可以让它按计划定时推送——直接说"每天早上九点给我推送科技股相关新闻"，
它会设置一个定时任务，到点主动把结果推给你，不需要你主动去问。

## 核心用法六：智能体市场

顶部栏的市场图标（或说"打开智能体市场"）会带你到一个卡片网格，每张卡片
是一个可以启用的智能体。点进任意一张：

- 还没启用的会看到 **Collect and chat** 按钮——点击即启用并直接进入对话
- 已启用的会看到 **Chat** 按钮直接进入对话，旁边还有 **Disable** 可以关闭它

**⚠️ 重要限制**：如果你是用官方的一键 Docker 部署（`docker compose up`），
默认镜像**只包含** Research Agent / Auto Trading Agent / News Agent 和
ValueCell 超级智能体这四个。智能体市场里可能还会列出巴菲特、芒格等"投资
大师人格"和 TradingAgents 多分析师模式，但它们各自需要独立的运行环境，
**默认镜像里没有启动它们的后端进程**——点了"Collect and chat"大概率会
卡住或报错，这不是你操作错了，是这些智能体本身需要额外的手动配置（参见
[RELEASE_CN.md](./RELEASE_CN.md)的范围说明）。

## 设置

顶部栏齿轮图标 → 左侧两个选项：

### General

- **Quotes Color**：涨跌颜色偏好，两个选项——"Green Up / Red Down"（涨绿
  跌红，国际习惯）或"Red Up / Green Down"（涨红跌绿，中国大陆习惯）。
  这个设置会影响全站所有价格涨跌的显示颜色，包括图表和自选列表。

### Memory

显示 AI 记住的、和你有关的信息（比如你的风险偏好、常问的问题类型），
用来让后续回复更贴合你。可以逐条查看和删除。

## 常见问题

**Q：我必须先看懂多智能体架构才能用吗？**
不需要。你只需要知道"打字问它就行"，它内部怎么调度不同智能体是它的事。

**Q：为什么有的问题它秒回，有的要等好几秒？**
简单问题（Super Agent 能直接回答的）秒回；复杂任务需要规划步骤、调用
专业智能体、可能还要查外部数据，自然会慢一些，过程会实时显示在界面上，
不是卡住了。

**Q：自动交易会不会自己乱花钱？**
默认是纸上交易，不涉及真实资金。要接入真实交易所需要两道独立的显式开关
（见[核心用法四](#核心用法四自动交易auto-trading-agent)），不会误触发。

**Q：我可以让好几个智能体同时工作吗？**
可以，直接在对话里提出跨领域的复合请求（比如"研究一下特斯拉，如果基本面
不错就设置自动交易并订阅它的新闻"），ValueCell Agent 会自己拆解调度。

**Q：历史对话会不会丢？**
不会，只要你没有执行 `docker compose down -v`（带 `-v` 会清空数据卷），
所有对话、自选列表、记忆都保留在持久化的数据卷里。

## 风险提示

- ValueCell 是技术工具，**不构成投资建议**
- 自动交易涉及真实资金风险，务必先用纸上交易充分验证策略
- AI 的分析和建议可能出错，任何交易决策的最终责任在你自己
- 投资有风险，入市需谨慎
